# VA-Tests-Perform
Сценарии автоматизированного тестирования (Vanessa Automation) для конфигурации 1C:Perform, адаптированные
к релизу 3.2.9.56.

## Откуда исходники

Первый коммит — набор вендора `github.com/1C-CPM/VA-Tests-Perform` без изменений (последний коммит вендора —
6c82f22 от 26.04.2024). С 12.11.2026 репозиторий вендора недоступен. Права на исходные сценарии принадлежат 1С;
лицензию вендор не указал.

## Что доработано и зачем

На актуальном релизе исходный набор не проходил. Правки идут отдельными коммитами поверх исходного набора, их
можно смотреть по истории, подробности — в сообщениях коммитов. Проверки сценариев не ослаблены.

- Под изменения релиза 3.2.9.56: справочники и формы, которые изменились в релизе, эталоны отчётов.
- Независимость от окружения: эталон шаблона Excel не зависит от текущего года, текст процедуры сравнивается без
  учёта вида перевода строки.

Проверено на Perform 3.2.9.56, платформе 8.3.24.1528 и Vanessa Automation 1.2.043.47: 1_НСИ 27 из 27,
3_Бюджетирование 239 из 239.

Подготовка базы и запуск — `Инструкция по запуску сценарных тестов.pdf` вендора.

## Ветка file-base-env

Нужна только для запуска на файловой базе с лицензией для разработчиков, на обычном стенде не нужна. Это `main`
плюс условия выполнения, проверки сценариев не меняются:

- подключение тестового клиента обёрнуто в `Попытка ... Исключение / И Пауза 30 / повторное подключение`:
  при медленном старте клиента первая попытка не успевает;
- в 20.09 после каждого закрытия клиента перед входом под другим пользователем — `И Пауза 45`: лицензия для
  разработчиков допускает не более 3 сеансов в одной информационной базе, а сеанс закрытого клиента освобождается
  с задержкой;
- в 20.09 после подключения `Бюджетирование4` — `И Пауза 10`: список сохранённых настроек экземпляра отчёта
  не успевал загрузиться к выбору настройки.

Проверено на файловой базе без Microsoft Excel: 1_НСИ 27 из 27, 3_Бюджетирование 230 из 239. Все 9 падений —
сценарии, которым нужен Excel.

## Зачем этот репозиторий

Тренировка работы с ИИ-помощником: через MCP Vanessa Automation помощник прогоняет набор на тестовой базе,
разбирает падения по журналу и снимкам экрана и исправляет сценарии, а человек проверяет и принимает правки.
